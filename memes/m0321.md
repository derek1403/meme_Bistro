# 對拖延症來說，週三是 Fibonacciday

![對拖延症來說，週三是 Fibonacciday](../images/m0321-fibonacciday-procrastination.png)

**一句話**：對拖延症患者來說，星期三不是 Wednesday，是 Fibonacciday——因為週三的工作量是週一跟週二的總和。

## 🍸 笑點解說
- **背景知識**：費氏數列每一項是前兩項之和：1, 1, 2, 3, 5, 8…
