# 2026 = 1⁰ + 2⁰ + … + 2026⁰

![2026 = 1⁰ + 2⁰ + … + 2026⁰](../images/m0408-2026-sum-of-zero-powers.png)

**一句話**：兩個 Soyjak 對著「2026 = 1⁰ + 2⁰ + 3⁰ + … + 2026⁰」驚呼。

## 🍸 笑點解說
- **梗在哪**：任何非零數的 0 次方都是 1，所以這就是 2026 個 1 相加——對任何年份都成立，一點都不神奇。
