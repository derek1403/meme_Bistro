# sudo 打開你的眼睛

![sudo 打開你的眼睛](../images/m0028-sudo-open-your-eyes.png)

**一句話**：身體不聽大腦的「睜開眼睛」，直到大腦加上 sudo。

## 🍸 笑點解說
- **背景知識**：Linux/macOS 裡 `sudo` 是用管理員（root）權限執行指令，一般使用者被拒絕的操作加上 sudo 就能強制執行。
- **梗在哪**：大腦第一次請求被身體「Nice try」拒絕，改用最高權限下指令，人就瞬間清醒（而且嚇醒）。
