# 港區國安法為香港經濟撐腰（齒輪版）

![港區國安法為香港經濟撐腰（齒輪版）](../images/m0129-hk-security-law-gears-jam.png)

**一句話**：官方宣傳圖把「國安法」「HK$」「經濟成長」畫成三個互相咬合的齒輪——三個齒輪兩兩互咬，會直接卡死，一個都轉不動。

## 🍸 笑點解說
- **背景知識**：兩個咬合的齒輪轉向相反。三個齒輪若兩兩互相咬合（形成三角形），A 逆時針 → B 順時針 → C 逆時針 → 但 C 又要讓 A 順時針，矛盾，整組卡死。
- **梗在哪**：本意是「互相帶動」，機構學上卻在說「互相卡死」。圖上標示來自官方媒體的 Facebook 貼文，網友看圖挑出了這個設計失誤。
