# 找到解法 → 我超猛 → 一堆 error → 毫無進展

![找到解法 → 我超猛 → 一堆 error → 毫無進展](../images/m0432-simulation-despair-cycle.png)

**一句話**：「好像找到解決方法了喔！」→「我現在超猛，用新方法做做看」→ 滿屏 ConfigTree error →「連續做了 10 個小時毫無進展」→ 回到第一步。中間紅字：「對不起，我可能比較笨，我還在想辦法搞懂這一切到底該怎麼運作。」
