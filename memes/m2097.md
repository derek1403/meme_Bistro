# LLM 只是線性代數——Through Linear Algebra all things are possible

![LLM 只是線性代數——Through Linear Algebra all things are possible](../images/m2097-through-linear-algebra-all-possible.png)

**一句話**：AI 反對者：「LLM 根本沒在思考，全都只是線性代數。」我：「首先，透過**線性代數**，萬事皆有可能，記下來。」

## 🍸 笑點解說
- **梗在哪**：原台詞出自《酒吧五傑》，是 "through **God** all things are possible"，這裡把「上帝」換成「線性代數」。大型語言模型的核心運算確實幾乎都是矩陣乘法。
