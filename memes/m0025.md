# 你把我的 XP 說一遍幹什麼

![你把我的 XP 說一遍幹什麼](../images/m0025-you-just-listed-my-fetish.png)

**一句話**：她自卑地列出「個子小、身材貧瘠、宅、社恐」，對方：你把我的 XP 念一遍幹嘛。

- **背景知識**：XP 是中國網路用語，來自「性癖（xìngpǐ）」拼音縮寫，指個人偏好的萌點。
