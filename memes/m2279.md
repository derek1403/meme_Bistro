# 朋友：我找到費馬最後定理的證明了——for a in range(1, infinity)

![朋友：我找到費馬最後定理的證明了——for a in range(1, infinity)](../images/m2279-fermat-proof-infinite-loop.png)

**一句話**：「我找到費馬最後定理的證明了」——一段三層巢狀迴圈，a、b、c 都從 1 跑到無窮大，檢查 aⁿ + bⁿ == cⁿ，找到就回傳 False，否則回傳 True。

## 🍸 笑點解說
- **梗在哪**：費馬最後定理說 n > 2 時 aⁿ + bⁿ = cⁿ 沒有正整數解。這段程式的 `return True` 永遠跑不到——最內層迴圈就要跑無窮久，連 b = 2 都到不了。暴力搜尋無法證明「不存在」，這也是 Wiles 要寫一百多頁證明的原因。
