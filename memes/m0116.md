# 突然出現的封閉積分符號

![突然出現的封閉積分符號](../images/m0116-contour-integral-in-novel.png)

**一句話**：日文書的段落分隔符號，看起來就是封閉曲線積分 ∮。

## 🍸 笑點解說
- **背景知識**：∮ 是沿封閉曲線的積分（例如電磁學的安培定律）。
- **梗在哪**：排版用的裝飾符號（類似 §）剛好長得像 ∮，理工人讀散文讀到一半突然被迫做積分。推主 ID 裡的 299792458 是光速（m/s）。
