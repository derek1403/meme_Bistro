# int、int*、int**：安妮亞指向約兒

![int、int*、int**：安妮亞指向約兒](../images/m3255-int-pointer-anya-yor.png)

**一句話**：約兒是 int；指著她的安妮亞是 int*；再指著那個安妮亞的另一個安妮亞是 int**。

## 🍸 笑點解說
- **梗在哪**：C 語言中 int* 是「指向 int 的指標」，int** 是「指向 int* 的指標」（指標的指標）。安妮亞的招牌指人動作，剛好把這層層指向關係畫成圖。
