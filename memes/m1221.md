# Unix 家族：1991 vs 2021

![Unix 家族：1991 vs 2021](../images/m1221-unix-1991-linux-2021.png)

**一句話**：1991 年，SCO Unix、Unixware、SunOS、Solaris、HP-UX、AIX 和一個肌肉壯漢 Linux 並肩坐在山丘上；2021 年，只剩 Linux 獨自坐在一排墓碑前。

## 🍸 笑點解說
- **背景知識**：九〇年代商業 Unix 百家爭鳴，但後來幾乎全部式微或停止開發；免費開源的 Linux 則吃下了伺服器、手機（Android）、超級電腦等市場，成為唯一的倖存者。
