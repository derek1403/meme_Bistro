# 為什麼寫個西洋棋程式那麼難

![為什麼寫個西洋棋程式那麼難](../images/m0640-chess-program-if-else.png)

**一句話**：用 print 畫出整個棋盤，然後 `if player == "e4":` 再 print 一整個新棋盤、`elif player == "d4":` 再一個……「為什麼寫個西洋棋程式那麼難😭」

## 🍸 笑點解說
- **梗在哪**：把每一種可能的走法都用 if-else 硬寫出來——西洋棋的可能局面數比宇宙原子還多。
