# 前有不得了的東西，但你沒資格

![前有不得了的東西，但你沒資格](../images/m0188-souls-message-no-qualification.png)

**一句話**：「前有某種不得了的東西，不過你沒資格啊，你沒資格。」「不能從這一側打開。」「可惡，可惡，可惡啊。」

## 🍸 笑點解說
- **背景知識**：《黑暗靈魂》《艾爾登法環》系列裡，玩家可以留下格式化訊息（「前有○○」），單向門則顯示「不能從這一側打開」。
- **梗在哪**：把魂系遊戲的 UI 疊在一張角色靠著門哭喊的動畫截圖上，完美重現「看得到拿不到」的崩潰。
