# 理想氣體 → 凡得瓦氣體：超級賽亞人

![理想氣體 → 凡得瓦氣體：超級賽亞人](../images/m0243-van-der-waals-super-saiyan.png)

**一句話**：PV = nRT 是比愛心的悟空；(P + an²/V²)(V − nb) = nRT 是超級賽亞人。

## 🍸 笑點解說
- **背景知識**：理想氣體方程假設分子沒有體積、彼此沒有吸引力。凡得瓦方程加入兩個修正：a 項修正分子間吸引力，b 項扣掉分子本身的體積，更貼近真實氣體。
