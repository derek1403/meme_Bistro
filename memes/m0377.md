# 假設 x = 2，假設正確

![假設 x = 2，假設正確](../images/m0377-assume-x-equals-2.png)

**一句話**：黑板上 8ˣ + 2x = 68，解法：「假設 x = 2。假設正確。」

## 🍸 笑點解說
- **梗在哪**：8² + 4 = 68，直接猜中。這題正經解要用到 Lambert W 函數，所以「猜」其實是最實際的解法。
