# 可以看出，雖然有點難

![可以看出，雖然有點難](../images/m0396-cycle-index-a-bit-difficult.png)

**一句話**：「It is possible, though a bit difficult, to see that for n vertices the cycle index is——」接著是一條橫跨整頁、五個連乘符號的巨型公式。

## 🍸 笑點解說
- **背景知識**：循環指標（cycle index）是 Pólya 計數定理的核心，用來計算在對稱性下不同構的圖或著色有幾種。
- **梗在哪**：教科書說「有點難」，實際上是這種等級——跟「顯然」「易證」是同一家族的謊言。
