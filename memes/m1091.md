# 凱薩琳．麗塔瓊斯 vs 黎曼 ζ 函數

![凱薩琳．麗塔瓊斯 vs 黎曼 ζ 函數](../images/m1091-zeta-jones-riemann-zeta.png)

**一句話**：文氏圖：Catherine Zeta-Jones 在找 Zorro，Riemann Zeta Function 在找 Zeros——交集：Complex arguments。

## 🍸 笑點解說
- **背景知識**：黎曼猜想是關於 ζ(s) 的非平凡零點是否都在實部 1/2 的直線上；ζ 函數的輸入是複數。麗塔瓊斯主演過《蒙面俠蘇洛》。
- **梗在哪**：Zorro/Zeros 諧音；complex arguments 同時是「複數輸入」和「複雜的爭吵」。
