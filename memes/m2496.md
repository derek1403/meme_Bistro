# 告訴我真相：(A+B)² = A² + B²

![告訴我真相：(A+B)² = A² + B²](../images/m2496-disjoint-curves-freshman-dream.png)

**一句話**：「告訴我真相，我準備好了。」「如果 A 和 B 是代數曲面上不相交的曲線，那麼 (A+B)² = A² + B²。」——她哭了。

## 🍸 笑點解說
- **梗在哪**：(a+b)² = a²+b² 是初學者最經典的錯誤（新生之夢）。但在代數曲面上，曲線的「平方」指交點數（自交數），展開是 A² + 2A·B + B²；A、B 不相交時 A·B = 0，交叉項消失，這個錯誤公式竟然成立了。
- 她哭，是因為一輩子被糾正的錯誤原來在某個地方是對的。
