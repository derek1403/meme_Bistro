# 最優美的數學不等式：π^(ei) + 1 ≠ 0

![最優美的數學不等式：π^(ei) + 1 ≠ 0](../images/m2195-pi-ei-plus-one-not-zero.png)

**一句話**：「最優美的數學不等式」：π^(ei) + 1 ≠ 0。

## 🍸 笑點解說
- **梗在哪**：歐拉恆等式 e^(iπ) + 1 = 0 被稱為「最美的數學等式」；這裡把 e 和 π 位置對調成 π^(ei)，式子就不成立了——於是變成一條「優美的不等式」。
