# What the hell is this?（Windows 11）

![What the hell is this?（Windows 11）](../images/m1828-noahs-ark-windows-11.png)

**一句話**：挪亞方舟上，挪亞指著一隻大象頭企鵝身的怪物：「這什麼鬼？」——牠叫「Windows 11」；旁邊站著大象（Windows 10）、企鵝（Linux）和小豬（Android）。

## 🍸 笑點解說
- **梗在哪**：暗示 Windows 11 是 Windows 10 和 Linux 生下的混血怪胎（例如內建 WSL 的 Linux 子系統）。
