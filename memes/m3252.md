# 過年說你會找不到對象？馬克士威：磁單極不存在，必成對偶

![過年說你會找不到對象？馬克士威：磁單極不存在，必成對偶](../images/m3252-maxwell-new-year-no-monopole.png)

**一句話**：「再這樣下去你會找不到對象啦。」馬克士威：「不用你操煩，磁單極並不存在，必成對偶，懂？」附 ∇·B = 0。

## 🍸 笑點解說
- **梗在哪**：∇·B = 0（高斯磁定律）表示磁場沒有源頭，也就是沒有單獨的 N 極或 S 極，磁極一定成對出現。既然「單極」不存在，自己也不可能一直單身。
