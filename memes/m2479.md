# 你的地址？實體地址？

![你的地址？實體地址？](../images/m2479-what-is-your-address-ip-mac.png)

**一句話**：問他地址，他答 IP；問「本地地址」，他答 127.0.0.1；問「實體地址（physical address）」，他答 MAC 位址。

## 🍸 笑點解說
- **梗在哪**：三個問題在網路術語裡都有另一個意思：address 是 IP 位址、local address 是本機迴路 127.0.0.1（localhost）、physical address 是網卡的 MAC 位址。工程師每次都照字面、用網路意義正確回答了，就是沒給住址。
