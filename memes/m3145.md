# 推特小鳥轉身變成 X

![推特小鳥轉身變成 X](../images/m3145-twitter-bird-becomes-x.png)

**一句話**：一隻藍色小鳥慢慢背過身去、越變越大越陰沉，最後正面轉成一團深藍色的毛球，胸前印著 X 標誌——2023 年推特改名 X 的那一刻。
