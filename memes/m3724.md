# 芭比 vs 奧本海默：兩個看起來差不多的積分

![芭比 vs 奧本海默：兩個看起來差不多的積分](../images/m3724-barbenheimer-integrals.png)

**一句話**：芭比笑著的是 $\int \frac{1}{x^3}\,dx = -\frac{1}{2x^2} + C$；叼菸一臉陰沉的奧本海默是 $\int \frac{1}{x^3+1}\,dx = \frac{1}{6}\left(-\log(x^2-x+1) + 2\log(x+1) + 2\sqrt{3}\tan^{-1}\frac{2x-1}{\sqrt{3}}\right) + C$。

## 🍸 笑點解說
- **梗在哪**：分母只多了一個 $+1$，積分就要用部分分式拆解，結果長出對數和反正切。2023 年《芭比》和《奧本海默》同天上映，一粉一黑的對比被叫做 Barbenheimer。
