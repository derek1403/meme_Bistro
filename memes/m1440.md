# (3/5, 4/5) 和 (-3/5, -4/5)：Arctan 說是同一張圖

![(3/5, 4/5) 和 (-3/5, -4/5)：Arctan 說是同一張圖](../images/m1440-arctan-same-picture.png)

**一句話**：「公司要你找出這兩張圖的差異：(3/5, 4/5) 與 (−3/5, −4/5)。」Arctan：「They're the same picture.」

## 🍸 笑點解說
- **背景知識**：用 arctan(y/x) 求角度時，兩點的 y/x 都是 4/3，得到同一個角度——但它們其實在第一與第三象限，相差 180°。這就是為什麼程式裡要用 atan2(y, x)。
