# Linear Regression：把 A 劈成 Q 和 R

![Linear Regression：把 A 劈成 Q 和 R](../images/m2332-linear-regression-qr-split.png)

**一句話**：美國隊長徒手把寫著「A」的木頭一把撕成兩半——左手一塊「Q」、右手一塊「R」。標題：線性迴歸。

## 🍸 笑點解說
- **梗在哪**：解線性迴歸（最小平方法）時，數值上穩定的做法是先把設計矩陣做 **QR 分解** A = QR（Q 正交、R 上三角），再用回代解 Rβ = Qᵀy，比直接算 (AᵀA)⁻¹ 穩定。
