# 改變你的思考方式（統計學家版）

![改變你的思考方式（統計學家版）](../images/m0223-change-thinking-statistician.png)

**一句話**：再騙啊 → 拒絕虛無假設；我不知道我猜猜 → 套用中央極限定理；差不多啦 → 母體參數在信賴區間內；我覺得碰上瓶頸了 → 自由度為 0。

## 🍸 笑點解說
- **背景知識**：虛無假設是「沒有差異」的預設，被拒絕代表不相信；中央極限定理讓不知道分布也能近似為常態；自由度為 0 代表資料已被參數完全決定，沒有空間估計誤差。
- **梗在哪**：把自我成長圖文的「換個說法更正向」，改成統計學家專用的術語包裝。
