# 3D、2D——ln(2)/ln(3) D

![3D、2D——ln(2)/ln(3) D](../images/m2303-cantor-dimension-ln2-ln3.png)

**一句話**：大腦越來越亮：3D 真人女生、2D 動漫角色雷姆——最高境界是一個康托爾集合，維度 ln(2)/ln(3) ≈ 0.63D。

## 🍸 笑點解說
- **梗在哪**：康托爾集合每次把線段切成三等份、丟掉中間那份，剩下 2 份、每份縮為 1/3，所以它的碎形（豪斯多夫）維度是 log 2 / log 3 ≈ 0.63——比 2D 老婆更「高級」的是 0.63 維的老婆。
