# 牛排熟度：Rare → Well Done → Congratulation → Epic → Legendary

![牛排熟度：Rare → Well Done → Congratulation → Epic → Legendary](../images/m1634-steak-doneness-legendary.png)

**一句話**：牛排熟度表：Rare、Medium Rare、Medium、Medium Well、Well Done——接著是 Congratulation（燒成黑炭）、Epic（還在發紅冒火的焦炭）、Legendary（整個廚房著火）。
