# |e^{iπ} π^{ie} i^{eπ}| = ？

![|e^{iπ} π^{ie} i^{eπ}| = ？](../images/m0670-abs-e-ipi-pi-ie-i-epi.png)

**一句話**：「√−1 = i，那麼 |e^{iπ} · π^{ie} · i^{eπ}| = ？」選項 1、e、π、以上皆是——主持人瞪大眼睛。

## 🍸 笑點解說
- **拆解**：
  - |e^{iπ}| = |−1| = 1。
  - π^{ie} = e^{ie·ln π}，是純虛數次方，模長 = 1。
  - i^{eπ} = (e^{iπ/2})^{eπ} = e^{ieπ²/2}，同樣模長 = 1。
- **答案**：三者相乘模長是 1，選 A。每一項看起來都很可怕，其實都在單位圓上。
