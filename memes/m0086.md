# 今年立方數歲，兩年前平方數歲

![今年立方數歲，兩年前平方數歲](../images/m0086-cube-age-square-two-years-ago.png)

**一句話**：今年立方數歲、兩年前平方數歲——請證明唯一的解是 27 歲。

## 🍸 笑點解說
- **背景知識**：題目等價於找正整數解 y² + 2 = x³。答案 x = 3（27 歲）、y = 5（25 歲）。
- **梗在哪**：這是費馬當年宣稱證明過的名題，嚴格證明要到 ℤ[√−2] 裡做唯一分解，遠超一般人的「年齡謎題」想像——把大學代數數論包裝成推特自我介紹。
