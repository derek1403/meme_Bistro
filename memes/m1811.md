# 男／女朋友 vs C++

![男／女朋友 vs C++](../images/m1811-partner-vs-cpp.png)

**一句話**：男／女朋友：需要不停花錢、化妝好幾小時、只有剛開始讓你開心、有問題時怪怪的不說話、常讓你失望、會劈腿、無法編譯成 CPU 指令——C++：100% 免費、光速、能駕馭就永遠開心、有問題會給你完整細節、永遠照你的意思做、不會劈腿、可以編譯。

## 🍸 笑點解說
- **梗在哪**：寫過 C++ 的人都知道「有問題會給你完整細節」其實是滿螢幕看不懂的模板錯誤訊息——這份比較表本身就是反諷。
