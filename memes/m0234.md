# 怎麼在三小時內睡滿八小時

![怎麼在三小時內睡滿八小時](../images/m0234-sleep-8-hours-in-3-relativity.png)

**一句話**：「怎麼在三小時內睡滿八小時？」——以 0.927 倍光速移動就行了。

## 🍸 笑點解說
- **背景知識**：狹義相對論的時間膨脹：Δt = γτ，其中 γ = 1/√(1 − v²/c²)。
- **梗在哪**：回答者認真算出 γ = 8/3、v ≈ 0.927c。但仔細想會發現方向反了：高速移動的是你，所以是「你只睡了 3 小時，外面過了 8 小時」——鬧鐘會以為你睡飽了，你本人並沒有。
