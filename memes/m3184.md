# OK → K → Potassium → 0k → −273.15°C

![OK → K → Potassium → 0k → −273.15°C](../images/m3184-pooh-ok-k-potassium-absolute-zero.png)

**一句話**：越來越高雅的維尼：回覆「OK」→「K」→「Potassium（鉀）」→「0k」→「−273.15°C」。

## 🍸 笑點解說
- **梗在哪**：K 是鉀的元素符號，所以 K 可以寫成 Potassium；0k 看起來像 0 K（絕對溫度零度），所以再換成攝氏的 −273.15°C。每一步都是同一個「ok」，只是越繞越遠。
