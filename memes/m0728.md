# 成年人黑話

![成年人黑話](../images/m0728-adult-code-words.png)

**一句話**：下次 = 星期八；以後 = 13 月；改天 = 32 號；有時間 = 25 點；原則上不行 = 可以；原則上可以 = 不行；我盡量 = 別指望我；這事不賴你 = 這事全 TM 賴你。
