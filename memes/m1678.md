# 原版 → 美顏 → 留長髮 → 學會化妝

![原版 → 美顏 → 留長髮 → 學會化妝](../images/m1678-pepe-beauty-filter-stages.jpg)

**一句話**：原版的醜醜綠色佩佩蛙——美顏後變成劍眉帥哥——留長髮——留更長（啊幹沒開到美顏）——長髮美顏——學會化妝後直接變成臉紅的美少女。
