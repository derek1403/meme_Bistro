# 假設 x = 1/3，欸幹假設對了

![假設 x = 1/3，欸幹假設對了](../images/m0584-assume-x-one-third.png)

**一句話**：老師出了超越方程 8ˣ + 6x = 4 當作業——「這題用假設法很好做：假設 x = 1/3，欸幹假設對了，所以 x = 1/3。」

## 🍸 笑點解說
- **驗算**：8^(1/3) = 2，2 + 6·(1/3) = 4，真的對了。和之前「8ˣ+2x=68 假設 x=2」是同一招。
