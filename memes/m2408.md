# 自由正壓 Rossby 波：相速度 vs 群速度

![自由正壓 Rossby 波：相速度 vs 群速度](../images/m2408-rossby-phase-group-naruto-run.png)

**一句話**：同一個 Rossby 波，相速度跟群速度用兩格火影跑表示——它們的方向不一定相同。

## 🍸 笑點解說
- **梗在哪**：正壓 Rossby 波的頻散關係是 ω = −βk/(k²+l²)（相對於平均風）。相速度 c = ω/k 永遠往西；群速度 ∂ω/∂k 在長波時也往西，但短波時卻會往東。所以波峰往一邊跑、能量往另一邊跑，大氣系學生第一次算到這裡都會懷疑人生。
