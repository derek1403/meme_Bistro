# 面無表情的心在抽鬼牌——但她的面具出賣了她

![面無表情的心在抽鬼牌——但她的面具出賣了她](../images/m3714-kokoro-poker-face-mask.png)

**一句話**：秦心拿著兩張牌讓對手抽，臉上完全沒有表情；但對手的手移到其中一張，她頭上的面具就變成哭臉，移到另一張就變成笑臉——撲克臉完全沒用。

## 🍸 笑點解說
- **背景知識**：東方 Project 的秦心是面具的付喪神，本人面無表情，情緒全靠頭上的能面具表現出來。
