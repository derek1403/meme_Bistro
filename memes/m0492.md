# /usr/bin/cat

![/usr/bin/cat](../images/m0492-usr-bin-cat.png)

**一句話**：一隻貓坐在桶子（bin）裡：/usr/bin/cat。

## 🍸 笑點解說
- **梗在哪**：`/usr/bin/cat` 是 Linux 上 `cat` 指令的實際路徑；bin 同時是「垃圾桶／桶子」。
