# if and only if → iff

![if and only if → iff](../images/m1452-seal-iff.png)

**一句話**：上圖：伸長脖子的海豹「if and only if」；下圖：被手一推、脖子縮成一團的海豹「iff」。

## 🍸 笑點解說
- **背景知識**：數學家把「若且唯若（if and only if）」縮寫成 iff——海豹被壓扁的樣子正好就是這個縮寫的過程。
