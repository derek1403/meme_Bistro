# 0:7 其實不是笑點，笑點是日本守門員 0 撲救

![0:7 其實不是笑點，笑點是日本守門員 0 撲救](../images/m1918-japan-keeper-zero-saves.png)

**一句話**：「0:7 其實不是笑點，笑點是日本守門員 0 撲救，也就是說這守門員甚至可以不上場也不影響比分。」——配圖是中國隊門將坐在地上一臉無奈，日本網友：「中國的門將，一副無計可施的表情」。
