# The data are… vs The data is…

![The data are… vs The data is…](../images/m0202-data-are-vs-data-is.png)

**一句話**：說「The data are」的是穿燕尾服的貴族海綿寶寶，說「The data is」的是肌肉猛男海綿寶寶。

## 🍸 笑點解說
- **背景知識**：data 源自拉丁文 datum 的複數，傳統學術寫作用 data are；但現代英文普遍把 data 當不可數名詞，說 data is。
- **梗在哪**：講究派優雅做作，實用派粗暴有力——兩種都有人堅持。
