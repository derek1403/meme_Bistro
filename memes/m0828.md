# 大家一起切 0 這塊蛋糕，除了 0÷0

![大家一起切 0 這塊蛋糕，除了 0÷0](../images/m0828-zero-over-zero-cake.png)

**一句話**：0−0、0+0、0×0、√0、0ⁿ 一起伸手切「0」這塊蛋糕——只有 0÷0 的手握拳，根本沒碰到蛋糕，還一臉心虛地笑。

## 🍸 笑點解說
- **背景知識**：其他運算的結果都是 0，但 0÷0 是「未定義」（在極限中是不定型），所以它不屬於「等於 0」的這一群。
- **註**：0ⁿ 在 n>0 時是 0，但 0⁰ 也是個爭議點。
