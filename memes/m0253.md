# 0! = 1 vs 0 != 1

![0! = 1 vs 0 != 1](../images/m0253-factorial-vs-not-equal.png)

**一句話**：數學家：0! = 1。程式設計師：0 != 1。兩邊都對。

## 🍸 笑點解說
- **梗在哪**：數學裡 0! 是零的階乘，定義為 1；程式語言裡 `!=` 是「不等於」，0 不等於 1 也成立。同一串字元、兩種意義、都是真命題。
