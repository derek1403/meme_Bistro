# 當代年輕人現狀（東方 Project 版）

![當代年輕人現狀（東方 Project 版）](../images/m3763-youth-status-touhou.png)

**一句話**：「當代年輕人現狀」用八個東方角色對應：睡眠狀況＝八雲紫、健康狀況＝帕秋莉、運氣＝鍵山雛、經濟狀況＝依神紫苑、脾氣＝純狐、情感狀況＝水橋帕露西、飯量＝西行寺幽幽子、考試的時候＝琪露諾。

## 🍸 笑點解說
- **梗在哪**：每個角色都有對應的設定：紫整天睡覺、帕秋莉體弱多病、雛是厄運之神、紫苑是窮神、純狐滿懷怨恨、帕露西是嫉妒的妖怪、幽幽子是大胃王、琪露諾是笨蛋（⑨）。
