# Co + 2Fe → Coffee、Ba + 2Na → Banana

![Co + 2Fe → Coffee、Ba + 2Na → Banana](../images/m3106-coffee-banana-chemistry-equation.png)

**一句話**：學生在化學題寫「Co + 2Fe → Coffee」「Ba + 2Na → Banana」——鈷加兩個鐵是咖啡、鋇加兩個鈉是香蕉；化學老師湯姆一腳把學生傑利踩在地上。
