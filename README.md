## 🏷️ 分類方式

每張迷因有一張卡片（`memes/m0001.md`），裡面記錄：

- **主題 `topic`**（單選，決定放在哪個畫廊）：數學、物理與自然科學、程式與 AI、學術與研究生活、語言與諧音、日常與生活、社會與地獄梗
- **笑點 `humor`**（可複選）
  - 🧠 **硬核**：要有學科背景才笑得出來
  - 👀 **直觀**：看圖就懂
  - 🔤 **諧音／文字梗**：雙關、諧音、字面意思
  - 🔥 **地獄梗**：拿敏感題材開玩笑
- **難度 `difficulty`**：★ 一看就懂 ・ ★★ 需要一點背景 ・ ★★★ 要會該學科。**★★ 以上一定附「🍸 笑點解說」**
- **標籤 `tags`**：自由關鍵字，方便搜尋

## ⚠️ 內容說明

- 收錄內容包含性暗示、死亡、種族、宗教、政治等題材的地獄梗。這類迷因卡片會標示 `content_warning`，在畫廊裡摺疊在「⚠️ 需斟酌」區塊，也不會出現在今日精選。
- 圖片皆為網路流傳的迷因，版權屬原作者；卡片的 `source` 欄位記錄圖上可見的出處。若你是原作者並希望移除，請開 issue。
