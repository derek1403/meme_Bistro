# 你打不倒我：新手之夢的逆襲

![你打不倒我：新手之夢的逆襲](../images/m2870-freshman-dream-binomial-mod-p.png)

**一句話**：二項式定理 $(x+y)^p = \sum_k \binom{p}{k} x^k y^{p-k}$ 說「你打不倒我」；錯誤的「$(x+y)^a = x^a + y^a$」說「我知道，但他可以」——召喚出 $(x+y)^p \equiv x^p + y^p \pmod{p}$。

## 🍸 笑點解說
- **梗在哪**：$(x+y)^a = x^a + y^a$ 是學生常犯的錯，俗稱「新手之夢（freshman's dream）」。但在模質數 p 時它竟然成立：因為當 $0<k<p$ 時，$\binom{p}{k}$ 都是 $p$ 的倍數，中間項全部消失。錯誤的公式在特定世界裡翻身成真。
