# 天氣好想出門 vs 出門 3 秒後的我

![天氣好想出門 vs 出門 3 秒後的我](../images/m1232-go-out-3-seconds-later.png)

**一句話**：天氣好，想著不如偶爾外出的我——躺在床上一臉期待；出門 3 秒之後的我——《霍爾的移動城堡》荒野女巫滿臉大汗、痛苦融化。
