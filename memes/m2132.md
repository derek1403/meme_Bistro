# Wait, working class politics is just maths!?——Always has been

![Wait, working class politics is just maths!?——Always has been](../images/m2132-working-class-just-maths.png)

**一句話**：「等等，勞工階級政治其實就是數學？！」「一直都是。」——旁邊寫著 P := {p | p 是人}、W: P → 2，W(p) = True 若 p 是勞工階級，否則 False。

## 🍸 笑點解說
- **梗在哪**：用集合論把「是不是勞工階級」寫成一個從人集合映到 **2 = {True, False}** 的函數（示性函數）——把政治口號硬翻成數學定義，然後宣稱政治就是數學。
