# LaTeX 手冊索引：infinite loop, 252——就在第 252 頁

![LaTeX 手冊索引：infinite loop, 252——就在第 252 頁](../images/m3284-latex-index-infinite-loop-252.png)

**一句話**：一本 LaTeX 書的索引頁寫著「infinite loop, 252」——而這一頁本身就是第 252 頁。想查無限迴圈，就會一直被指回這一頁。
