# 身分盜竊不是開玩笑的！

![身分盜竊不是開玩笑的！](../images/m0902-identity-theft-binary-card.png)

**一句話**：「Identity theft is not something to joke about!」——一隻戴手套的手從包包裡偷走一張寫著 1 0 0 / 0 1 0 / 0 0 1 的卡片。

## 🍸 笑點解說
- **梗在哪**：卡片上是 3×3 單位矩陣（identity matrix）——偷走的是「identity」。
