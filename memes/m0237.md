# 我沒有說「若且唯若」

![我沒有說「若且唯若」](../images/m0237-iff-ww3-girlfriend.png)

**一句話**：2018 年「當我女朋友？」「除非第三次世界大戰開始。」今天：「Yo。」「我沒說是 if and only if。」

## 🍸 笑點解說
- **背景知識**：「P only if Q」表示 Q 是 P 的必要條件（P → Q），不代表 Q 發生 P 就一定發生；「if and only if」（若且唯若）才是雙向。
- **梗在哪**：男生以為世界大戰開打（Q 成立）就能交往，但女生當年只給了必要條件，沒給充分條件——邏輯學的拒絕。
