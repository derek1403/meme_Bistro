# 25 個圓、36 個圓，合理——49 個圓：WHAT THE…

![25 個圓、36 個圓，合理——49 個圓：WHAT THE…](../images/m2358-circle-packing-49.png)

**一句話**：正方形裡最密排 25 個圓是 5×5 方格，「嗯合理」；36 個是 6×6，「嗯看得出來」；49 個卻不是 7×7，而是一團歪七扭八的排法——她整張臉嚇到發白。

## 🍸 笑點解說
- **梗在哪**：在正方形中放 n 個等大的圓、讓圓盡量大，對 n = k² 時直覺上該是方格排列；這在 36 以內都對，但到了 49 個時，已知更好的排法反而是看似雜亂的交錯排列。
