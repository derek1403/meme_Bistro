# HTTP 200 回傳 error 500

![HTTP 200 回傳 error 500](../images/m0590-http-200-error-500.png)

**一句話**：後端傳紙條給前端——前端打開一看：`HTTP/1.1 200 { "error": 500 }`。

## 🍸 笑點解說
- **背景知識**：HTTP 200 表示成功，500 表示伺服器錯誤。
- **梗在哪**：有些 API 不管成敗一律回 200，再把錯誤碼塞進 body 裡——前端只能怒瞪。
