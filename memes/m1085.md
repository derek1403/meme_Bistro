# Excuse me！（古明地戀叫服務生）

![Excuse me！（古明地戀叫服務生）](../images/m1085-koishi-excuse-me-waiter.png)

**一句話**：古明地戀在餐廳一次次舉手喊「Excuse me」，服務生完全沒注意到她——最後她趴在桌上崩潰大喊。

## 🍸 笑點解說
- **背景知識**：東方 Project 的古明地戀能力是「操縱無意識」，別人不會注意到她的存在。
