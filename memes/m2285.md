# Google 翻譯：hello world → Java

![Google 翻譯：hello world → Java](../images/m2285-google-translate-hello-world-java.png)

**一句話**：Google 翻譯左邊輸入「hello world」，右邊語言選 Java——翻出來是一整段 `class Simple { public static void main(String args[]) { System.out.println("hello world"); } }`，一句話要寫五行。
