# π 不能寫成分數？我可以

![π 不能寫成分數？我可以](../images/m0246-pi-as-fraction-hbar.png)

**一句話**：「你不可能把 π 寫成分數！」「我可以：π = h / 2ℏ。」

## 🍸 笑點解說
- **背景知識**：π 是無理數，不能寫成兩個**整數**的比。物理中約化普朗克常數定義為 ℏ = h/2π，移項就得到 π = h/(2ℏ)。
- **梗在哪**：形式上確實是「分數」，只是分子分母都不是整數——技術上正確，但對方氣炸。
