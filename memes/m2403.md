# Happy IT Day 蛋糕——結尾的 <cake> 沒關好

![Happy IT Day 蛋糕——結尾的 <cake> 沒關好](../images/m2403-html-cake-unclosed-tag.png)

**一句話**：蛋糕上用 HTML 寫著 `<cake type=chocolate>`、`<frosting>vanilla</frosting>`……`Happy IT Day!`——最後一行應該是 `</cake>` 卻寫成 `<cake>`，而且 `</message>` 前面根本沒開過 `<message>`。
