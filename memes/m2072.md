# 64 bit computer：x + 1/10¹⁶, is this x?

![64 bit computer：x + 1/10¹⁶, is this x?](../images/m2072-64bit-is-this-x.png)

**一句話**：「這是蝴蝶嗎？」梗圖：64 位元電腦看著 x + 1/10¹⁶ 問：「這是 x 嗎？」

## 🍸 笑點解說
- **梗在哪**：64 位元雙精度浮點數大約只有 16 位有效數字（機器精度約 2.2×10⁻¹⁶），所以 x ≈ 1 時加上 10⁻¹⁶ 會被捨入掉，電腦真的會判定 x + 10⁻¹⁶ == x。
