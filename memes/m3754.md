# 那當然買更有用的東西囉——東方 fumo

![那當然買更有用的東西囉——東方 fumo](../images/m3754-buy-more-useful-things-touhou.png)

**一句話**：廣告裡的媽媽說：「那當然買更有用的東西囉。」下一格兩人開心地舉起東方 Project 的芙蘭朵露 fumo、蕾米莉亞 fumo 和靈夢的周邊——對東方迷來說這就是「最有用的東西」。

## 🍸 笑點解說
- **梗在哪**：幾乎所有東方 Project 的角色都有 fumo 布偶，對東方迷來說收集它們比任何實用品都重要，所以廣告台詞「買更有用的東西」在這裡是反話也是真心話。
