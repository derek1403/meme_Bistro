# 日文的 Bug 與你的 Code

![日文的 Bug 與你的 Code](../images/m0923-bug-your-code-japanese.png)

**一句話**：「女」是日文的 "Bug"——「姦」（三個女）是日文的 "Your Code"。

- **梗在哪**：一個 bug 是一個「女」，你的程式碼就是一堆 bug 疊在一起。（純屬玩笑，不是真正的日文意思。）
