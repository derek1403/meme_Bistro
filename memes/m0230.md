# 所有人 vs JavaScript 工程師的分號鍵

![所有人 vs JavaScript 工程師的分號鍵](../images/m0230-javascript-semicolon-key.png)

**一句話**：一般人的分號鍵乾淨如新；JavaScript 工程師的分號鍵被磨到快看不見。

## 🍸 笑點解說
- **梗在哪**：JavaScript 有「自動分號插入（ASI）」，分號其實可以省略；但為了避免 ASI 造成的詭異 bug，很多人每行都手動加分號，於是分號鍵磨損最嚴重。（也有人會反過來說 JS 工程師根本不打分號。）
