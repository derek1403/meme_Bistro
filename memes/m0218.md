# (x, y, z) ↦ (x, y, 0)

![(x, y, z) ↦ (x, y, 0)](../images/m0218-projection-dog-flattened.png)

**一句話**：站著的長毛獵犬，經過投影變換後——整隻平躺在草地上。

## 🍸 笑點解說
- **背景知識**：(x, y, z) ↦ (x, y, 0) 是三維空間到 xy 平面的正交投影，把高度 z 全部歸零。
- **梗在哪**：原本坐著的獵犬被「壓扁」成一張躺平的狗毯，完美示範什麼叫失去一個維度。
