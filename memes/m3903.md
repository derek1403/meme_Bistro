# 2+2=4、2×2=4，所以 + = ×——愛因斯坦被架住：冷靜！冷靜！

![2+2=4、2×2=4，所以 + = ×——愛因斯坦被架住：冷靜！冷靜！](../images/m3903-plus-equals-times.jpg)

**一句話**：$2+2=4$、$2\times 2=4$，$\therefore 2+2=2\times 2 \Rightarrow +=\times$。下面愛因斯坦氣到要衝過去打人，霍金和另一位科學家死命架住他：「冷靜！冷靜！」
