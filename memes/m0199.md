# 撞穿牆壁的兩人

![撞穿牆壁的兩人](../images/m0199-mokou-kaguya-through-wall.png)

**一句話**：牆上出現兩個人形洞，外面的人一轉頭——妹紅和輝夜一臉若無其事地站在洞後。

## 🍸 笑點解說
- **背景知識**：東方 Project 的藤原妹紅與蓬萊山輝夜都是不老不死之身，兩人是宿敵，常常打到天翻地覆。
- **梗在哪**：卡通式的「撞牆留下人形洞」，兩人事後裝作什麼都沒發生。
