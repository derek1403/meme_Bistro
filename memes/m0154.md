# 當 x = y 時，x = y

![當 x = y 時，x = y](../images/m0154-when-x-equals-y-x-is-y.png)

**一句話**：題目「設 y = 9/5 x + 32，當 x = y 時，x = ＿＿」，學生填：y。合理，憑什麼不給我對？

## 🍸 笑點解說
- **正解**：x = 9/5 x + 32 → x = −40。這條式子正是攝氏轉華氏，所以答案就是「−40 度時攝氏等於華氏」（見 SMBC 猴掌那張）。
- **梗在哪**：學生的答案在邏輯上完全正確，只是什麼都沒回答。
