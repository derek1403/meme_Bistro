# 當我長大後我想和媽咪一樣——其實是在賣最後一把雪鏟

![當我長大後我想和媽咪一樣——其實是在賣最後一把雪鏟](../images/m3685-mommy-snow-shovel.jpg)

**一句話**：小孩的畫「When I grow up, I want to be like mommy!」：媽媽站在一根長桿旁，周圍一群男人拿著鈔票，看起來像鋼管舞。媽媽寫信給老師澄清：「我從未當過脫衣舞孃，我在五金百貨工作。暴風雪來襲前店裡很忙，她畫的是我正在賣出最後一把雪鏟。」
