# 看得懂這段程式碼，就對店員說通關密語換免費三明治

![看得懂這段程式碼，就對店員說通關密語換免費三明治](../images/m2455-free-sandwich-js-encryption.png)

**一句話**：三明治店門口的黑板寫著一段 JavaScript，看得懂的人可以說出今日密語換一份免費三明治。

## 🍸 笑點解說
- **解法**：str2 是把 "itpyr" 反轉得到 "rypti"，request 回傳 str3 + str2 + str1 = "enc" + "rypti" + "on"，也就是 **encryption**（加密）。
