# 雕蟲小技竟敢班門弄斧

![雕蟲小技竟敢班門弄斧](../images/m0326-quintic-trig-substitution.png)

**一句話**：「解 x⁵ − 5x⁴ − 30x³ − 30x² + 5x + 3 = 0 的所有實根」——回覆一行行三角代換，最後 x = (√2/2)·sec((1/5)·arccos(√2/4) + 2kπ/5) − 1。

## 🍸 笑點解說
- **背景知識**：一般五次方程沒有根式解（阿貝爾–魯菲尼定理），但這題是特別設計的：令 y = x+1 可化成 y⁵ − 10y⁴ + 20y² − 8 = 0，再代入 y = 1/(√2 cos θ)，就變成五倍角公式 16cos⁵θ − 20cos³θ + 5cosθ = cos 5θ。
- **梗在哪**：出題者以為能難倒人，結果被一套漂亮的三角代換秒殺。
