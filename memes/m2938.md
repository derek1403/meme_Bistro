# 用微積分基本定理「證明」e^x 的泰勒級數

![用微積分基本定理「證明」e^x 的泰勒級數](../images/m2938-fundamental-theorem-e-x-series.png)

**一句話**：從 $e^x = \int e^x\,dx$ 出發，把積分當成數字移項得 $(1 - \int dx)\,e^x = 0$，再把 $1/(1-\int)$ 展開成幾何級數 $1 + \int + \int^2 + \int^3 + \cdots$，作用在 0 上，竟然得到 $e^x = \sum x^n/n!$。

## 🍸 笑點解說
- **梗在哪**：每一步都在亂來：把積分符號當成可以提出來的數、還除以它；右邊乘以 0 本來應該是 0。但如果把 ∫ 理解成「從 0 到 x 積分的算子」再加上積分常數，這串操作在算子理論裡其實有合法版本（Neumann 級數），最後結果也真的是對的。正如貼文者說的：「好扯，但最後是對的。」
