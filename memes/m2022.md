# Find a C such that F(x) = ∫_C f(x) ds

![Find a C such that F(x) = ∫_C f(x) ds](../images/m2022-line-integral-find-c.png)

**一句話**：超級爸爸三段變臉：「找 f 使 F = ∫_C f ds」還能笑、「找 F」開始褪色、「找一條曲線 C 使 F = ∫_C f ds」直接變成黑白恐怖臉。

## 🍸 笑點解說
- **梗在哪**：線積分平常是「路徑 C 給定、把被積函數積出來」；反過來要你找出**路徑本身**，就成了沒有標準解法的逆問題（類似變分法）——越往下越不是人做的題目。
