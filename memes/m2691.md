# 媽，三弟是不是長得有點太超過了？TREE(3)

![媽，三弟是不是長得有點太超過了？TREE(3)](../images/m2691-tree-3-brother.png)

**一句話**：拿著小樹枝的 TREE(2) 問媽媽：「三弟是不是長得有點太超過了？」旁邊的 TREE(3) 是扛著神器巨劍的肌肉巨人。

## 🍸 笑點解說
- **梗在哪**：TREE 函數來自 Kruskal 樹定理的組合問題。TREE(1) = 1、TREE(2) = 3，都很小；但 TREE(3) 大到難以想像，遠遠超過葛立恆數，一般的數學記號根本寫不出來。兄弟之間的差距，是從 3 直接跳到超越想像。
