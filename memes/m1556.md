# 兩個白痴在一起就會一起死：87 + 87 = 174

![兩個白痴在一起就會一起死：87 + 87 = 174](../images/m1556-two-idiots-die-together.png)

**一句話**：投影片寫著：「兩個白痴在一起，就會一起死：87 + 87 = 174」。

## 🍸 笑點解說
- **梗在哪**：台灣網路用語「87」＝白癡（諧音「白痴」）；174 念起來像「一起死」。
