# 神社：java.lang.StackOverflowError

![神社：java.lang.StackOverflowError](../images/m0385-stackoverflow-wishes.png)

**一句話**：初詣參拜者 A 許願「希望下一位的願望能實現」、B 許願「希望前一位的願望能實現」——神社：Exception in thread 'main' java.lang.StackOverflowError。

## 🍸 笑點解說
- **背景知識**：兩個函式互相呼叫、沒有終止條件，就會無限遞迴，直到堆疊溢位（stack overflow）。
- **梗在哪**：同一條推文串還有惡魔三個願望版，以及湯婆婆遇到 SQL 注入名字（`'; DROP TABLE employee`）——《神隱少女》的「奪取名字」直接把員工資料表刪了。
