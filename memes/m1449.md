# A single person's keyboard

![A single person's keyboard](../images/m1449-single-persons-keyboard.png)

**一句話**：正常人的鍵盤 vs 單身者的鍵盤——單身者鍵盤上左 Ctrl、左 Shift 和 N 三個鍵的字全被磨掉了。

## 🍸 笑點解說
- **梗在哪**：Ctrl + Shift + N 是 Chrome 開「無痕視窗」的快捷鍵——單身的人天天按，按到字都磨光了（暗示常看成人網站）。
