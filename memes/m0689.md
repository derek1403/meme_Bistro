# 1·3·5·7·… = 0

![1·3·5·7·… = 0](../images/m0689-odd-product-equals-zero.png)

**一句話**：令 x = 1·2·3·4·5⋯，拆成奇數乘偶數、偶數再拆成 (1·2·3⋯)(2·2·2⋯) = x·2^∞，於是 1·3·5·7⋯ = 1/2^∞ = 0——兩個 Soyjak 驚呼。

## 🍸 笑點解說
- **錯在哪**：x 是發散的無窮乘積，根本不是一個數，不能把它當成數約分；「2^∞」也不是數。每一步都在拿無窮大做代數運算，所以才能得出正整數相乘等於 0。
