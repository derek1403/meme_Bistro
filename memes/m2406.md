# Knowledge 96%、Workhard 98%……Touhou = 100%

![Knowledge 96%、Workhard 98%……Touhou = 100%](../images/m2406-touhou-equals-100-percent.png)

**一句話**：把 A～Z 當作 1～26 加總：Knowledge = 96、Workhard = 98、Luck = 47、Love = 54、Money = 72、Leadership = 89——都不是 100。真正能讓人生圓滿的是 Touhou（東方）= 20+15+21+8+15+21 = 100！#幻想鄉才是永遠
