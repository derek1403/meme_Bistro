# 所有現代數位基礎建設（2025 版）

![所有現代數位基礎建設（2025 版）](../images/m0451-digital-infrastructure-cloudflare.png)

**一句話**：更新版積木塔：Cloudflare 和 AWS 是兩塊關鍵小積木、AI 在旁邊拿搖桿亂搖、left-pad 和 CrowdStrike 標在要命的位置、鯊魚在咬海底電纜、最底層是寫動態陣列的 C 工程師和 ASML 光刻機。

## 🍸 笑點解說
- **背景知識**：各標註都是真實事件：left-pad（2016 年一個 11 行的 npm 套件被下架，搞垮半個 JavaScript 生態系）、CrowdStrike（2024 年更新錯誤造成全球 Windows 藍屏）、Cloudflare 與 AWS 當機（一出事就半個網路掛掉）、鯊魚咬海底電纜。
