# 答案寫 True 或 False：學生寫了 Frlse

![答案寫 True 或 False：學生寫了 Frlse](../images/m3162-true-false-ambiguous-handwriting.png)

**一句話**：英文老師：「答案寫 True 或 False。」學生寫了一個 T 像 F、中間 r 像 a、u 像 l 的「Frlse」——兩種都能改判，學生指著太陽穴一臉聰明，老師一臉無言。
