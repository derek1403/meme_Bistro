# Matrix World：一張圖看懂所有矩陣的分類

![Matrix World：一張圖看懂所有矩陣的分類](../images/m3794-matrix-world-strang.png)

**一句話**：用一層層的橢圓畫出矩陣家族：最外層是一般 $m\times n$ 矩陣（$A = CR$、SVD $A = U\Sigma V^T$），往內是方陣、可對角化、正規矩陣，再到對稱、正交、正定、投影、置換，最中心是單位矩陣 $I$ 和零矩陣 $O$。

## 🍸 笑點解說
- **梗在哪**：這其實是一張正經的線性代數整理圖，由 Kenji Hiranabe 在 MIT 教授 Gilbert Strang 協助下繪製。學線代的人看到會有「原來是這樣包含關係」的頓悟，沒學過的人只會看到滿滿的符號——宅宅限定的「好笑」。
