# 角度是 i 的直角三角形

![角度是 i 的直角三角形](../images/m0440-right-triangle-angle-i.png)

**一句話**：一個直角三角形，斜邊 2e、鄰邊 1+e²、對邊 √(2e² − e⁴ − 1)，夾角是 i。

## 🍸 笑點解說
- **背景知識**：cos(i) = cosh(1) = (e + 1/e)/2 = (1+e²)/(2e)，剛好是鄰邊/斜邊。
- **梗在哪**：對邊² = 4e² − (1+e²)² = −(e²−1)² < 0，所以對邊其實是虛數 i(e²−1)——一個「完全正確」但畫不出來的三角形。
