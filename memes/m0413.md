# 鴿籠原理 → 強鴿籠原理 → 強鴿-籠原理

![鴿籠原理 → 強鴿籠原理 → 強鴿-籠原理](../images/m0413-strong-pigeon-hole-principle.png)

**一句話**：鴿籠原理 → 強-鴿籠原理（N(R−1)+1 個物體放進 N 個箱子，至少一箱有 R 個）→ 強鴿-籠原理：鴿子夠大夠強，想進哪個籠子都行，把裡面的小鴿子擠出去就好。

## 🍸 笑點解說
- **梗在哪**：前兩層是真的數學定理；第三層把「強」的斷詞位置改了，從「強化版的鴿籠原理」變成「強壯的鴿子的籠子原理」。
