# 生活就像判別式

![生活就像判別式](../images/m0001-discriminant-stay-positive.png)

**一句話**：只要保持正向（b²−4ac > 0），人生就永遠有解。

## 🍸 笑點解說
- **背景知識**：一元二次方程 ax²+bx+c=0 的判別式 D = b²−4ac。D > 0 有兩個相異實根、D = 0 一個重根、D < 0 沒有實根（拋物線不碰 x 軸）。
- **梗在哪**：positive 同時是「正數」和「樂觀」，solutions 同時是「方程的解」和「人生的解方」。心靈雞湯剛好是一條數學定理。
- 圖中每個人頭都被換成一條拋物線，有的碰到 x 軸、有的沒碰到，正好是 D 的三種情況。
