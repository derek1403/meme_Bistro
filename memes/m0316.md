# He's a smooth operator

![He's a smooth operator](../images/m0316-smooth-operator-c-infinity.png)

**一句話**：T ∈ C^∞——♪ He's a smooth operator ♪

## 🍸 笑點解說
- **背景知識**：C^∞ 是無限次可微（光滑）函數的集合；T 常用來表示算子（operator）。
- **梗在哪**：Sade 的名曲〈Smooth Operator〉原意是「圓滑的情場高手」，這裡直接照字面變成「光滑的算子」。
