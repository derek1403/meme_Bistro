# 用 Python 印出日曆

![用 Python 印出日曆](../images/m0861-python-calendar-2012.png)

**一句話**：「Calendar in Python」——兩行程式碼 import calendar、print(calendar.month(2012, 12))，輸出 2012 年 12 月的月曆。

## 🍸 笑點解說
- **梗在哪**：這類「看起來很厲害」的程式教學圖，其實只是在呼叫標準函式庫；而 2012 年 12 月正是「世界末日」那個月。
