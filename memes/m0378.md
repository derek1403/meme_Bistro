# ∫ devil = evil

![∫ devil = evil](../images/m0378-integral-devil-evil.png)

**一句話**：∫ devil = evil。

## 🍸 笑點解說
- **梗在哪**：把 devil 拆成 d + evil，d 當成積分符號裡的「d」，所以 ∫ d(evil) = evil。
