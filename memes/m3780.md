# 連續說可愛 3 天、1 個月、3 個月、半年

![連續說可愛 3 天、1 個月、3 個月、半年](../images/m3780-keep-saying-cute-six-months.png)

**一句話**：每天稱讚短髮女生可愛：3 天時她還笑著反問「可愛的人是妳吧～」；1 個月時開始害羞轉頭；3 個月時穿上對方送的衣服；半年後穿著對方送的睡衣臉紅地說：「這是……專屬於妳的喔。」
