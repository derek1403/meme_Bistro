# 數學告訴你：凸開集同胚於 n 維開球

![數學告訴你：凸開集同胚於 n 維開球](../images/m2707-homeomorphic-open-ball.png)

**一句話**：生物說你有 7% 是血、化學說你有 70% 是水、物理說你有 99.999% 是空的；數學說 ℝⁿ 的凸開子集都同胚於 n 維開球——「我是同胚的？」「別害怕 n 維開球。」

## 🍸 笑點解說
- **梗在哪**：前三格是常見的「科學看人類」感性圖。第四格換成一條完全抽象的拓撲定理：任何凸的開集都能連續變形成一顆開球。它跟「你」一點關係都沒有，卻用同樣的語氣講出來。
