# 理科資優生的麻將教學：n·aaa + m·ABC + DD

![理科資優生的麻將教學：n·aaa + m·ABC + DD](../images/m2436-mahjong-formula-naaa-mabc-dd.jpg)

**一句話**：理科資優生說不會打麻將，朋友一句「n·aaa + m·ABC + DD 就是胡了，n、m 可以等於 0」，他秒懂——刻子、順子加一對眼，就是胡牌的基本型。
