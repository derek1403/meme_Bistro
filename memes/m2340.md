# 在 C++ 裡，friend 可以存取 private parts

![在 C++ 裡，friend 可以存取 private parts](../images/m2340-cpp-friends-private-parts.png)

**一句話**：「她說她把我當朋友。我告訴她在 C++ 裡，Friends 可以存取 private parts。」「她生氣了說我總是把人當 Objects。」「但我只是說她很有 Class！」「我爸看到這個笑話很不爽，我被移出 Inheritance（遺產）了。」

## 🍸 笑點解說
- **梗在哪**：每個詞都是物件導向術語的雙關：friend 函數能存取 private 成員（private parts 也指私處）、object 物件／物化、class 類別／有氣質、inheritance 繼承／遺產。
