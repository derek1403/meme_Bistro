# 超時空輝夜姬我看的是黑毛

![超時空輝夜姬我看的是黑毛](../images/m0298-kaguya-black-hair-houraisan.png)

**一句話**：「我去看了你們那個超時空輝夜姬，音樂很好聽但太難打了，而且你們說有白毛黃毛，我怎麼看的是個黑毛？」

## 🍸 笑點解說
- **梗在哪**：他把動畫《超時空輝耀姬》搞混成東方 Project 的蓬萊山輝夜（黑長髮），「太難打」是指東方的彈幕射擊遊戲。
