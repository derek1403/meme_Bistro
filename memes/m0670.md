# |e^{iπ} π^{ie} i^{eπ}| = ？

![|e^{iπ} π^{ie} i^{eπ}| = ？](../images/m0670-abs-e-ipi-pi-ie-i-epi.png)

**一句話**：「$\sqrt{-1} = i$，那麼 $|e^{i\pi} \cdot \pi^{ie} \cdot i^{e\pi}| = ？$」選項 1、e、π、以上皆是——主持人瞪大眼睛。

## 🍸 笑點解說
- **拆解**：
  - $|e^{i\pi}| = |-1| = 1$。
  - $\pi^{ie} = e^{ie\ln\pi}$，是純虛數次方，模長 = 1。
  - $i^{e\pi} = (e^{i\pi/2})^{e\pi} = e^{ie\pi^2/2}$，同樣模長 = 1。
- **答案**：三者相乘模長是 1，選 A。每一項看起來都很可怕，其實都在單位圓上。
