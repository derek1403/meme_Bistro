# Please disable adblock——overflow-y: visible

![Please disable adblock——overflow-y: visible](../images/m1216-adblock-overflow-visible.png)

**一句話**：點開有趣的文章——「請關閉廣告封鎖才能繼續閱讀」——打開開發者工具，把 `html { overflow-y: visible; }` 改回來，章魚哥雙眼發光躺回躺椅。

## 🍸 笑點解說
- **梗在哪**：很多網站的「擋廣告偵測」只是在頁面蓋一層遮罩、再把捲軸鎖住（overflow: hidden），懂一點 CSS 就能自己解除。
