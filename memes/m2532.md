# Windows 10 發表：那 Windows ⑨ 呢？

![Windows 10 發表：那 Windows ⑨ 呢？](../images/m2532-windows-9-cirno.png)

**一句話**：微軟宣布 Windows 10，東方的琪露諾眼眶含淚：「Windows ⑨ 呢？」

## 🍸 笑點解說
- **梗在哪**：微軟從 Windows 8 直接跳到 10，跳過了 9。東方 Project 的冰之妖精琪露諾以笨出名，粉絲用「⑨」當她的代號（出自官方手冊裡「バカ」旁邊標的 ⑨）。被跳過的 9，剛好就是她。
