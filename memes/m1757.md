# 馬克勞林 vs 泰勒

![馬克勞林 vs 泰勒](../images/m1757-maclaurin-vs-taylor-bus.png)

**一句話**：公車兩側的窗戶——左邊馬克勞林看著一面石壁一臉哀傷；右邊泰勒對著美麗的山景開心微笑。

## 🍸 笑點解說
- **背景知識**：麥克勞林級數其實就是在 x = 0 展開的泰勒級數——明明只是特例，還被冠了自己的名字，卻永遠活在泰勒的光環之下。
