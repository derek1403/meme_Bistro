# 用 Desmos 函數畫動漫女孩

![用 Desmos 函數畫動漫女孩](../images/m0850-desmos-anime-girl.png)

**一句話**：左邊是一整排帶定義域限制的分段函數 f(x) = {41.96 ≤ x ≤ 50.19 : −(−13.2+0.279x)^2.4 + 61.1}……右邊畫出了一個動漫少女的臉。
