# If those hard drives could still read, they'd be very upset

![If those hard drives could still read, they'd be very upset](../images/m1945-ssd-hard-drives-upset.png)

**一句話**：窗外舉牌：「SSD 更快更可靠。」——教室裡一群頭是傳統硬碟的學生；老師：「如果那些硬碟還能讀的話，它們一定會很不爽。」

## 🍸 笑點解說
- **梗在哪**：原台詞是「如果那些孩子會讀字的話」——硬碟的「讀取（read）」和「閱讀」雙關，順便嘲諷 HDD 老是讀取失敗。
