# lim 包子 = 饅頭（餡 → 0）

![lim 包子 = 饅頭（餡 → 0）](../images/m0328-lim-baozi-mantou.png)

**一句話**：黑板上寫著：當餡 → 0，lim 包子 = 饅頭；當餡 → +∞，lim 包子 = 丸子。

## 🍸 笑點解說
- **梗在哪**：用極限的寫法描述包子的兩個極端：沒有餡就是饅頭，全部都是餡就是丸子。字幕還很認真地說「對於基礎知識的無知」。
