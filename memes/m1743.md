# Read this. It will change you.

![Read this. It will change you.](../images/m1743-d-dx-book-changes-you.png)

**一句話**：1/x 遞給 x² 一本書：「讀讀看，它會改變你。」x² 讀完變成 2x：「wow」——2x 再把書遞給 $e^x$，$e^x$ 讀完聳肩：「還好吧。」2x：「怎麼可能有人不被這本書影響？？」——書名：$d/dx$。

## 🍸 笑點解說
- **背景知識**：對 x² 微分得 2x；而 $e^x$ 微分後還是 $e^x$——唯一不會被 $d/dx$ 改變的函數（至少差一個常數倍）。
- **額外細節**：遞書的 1/x 本身就是 ln x 被微分後的結果。
