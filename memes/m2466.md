# Matlab 寫的原型演算法：噴你一臉 Index Error

![Matlab 寫的原型演算法：噴你一臉 Index Error](../images/m2466-matlab-index-errors-cough.png)

**一句話**：演算法原型用 Matlab 寫，移植的時候朝你咳了一大團「Index Errors」。

## 🍸 笑點解說
- **梗在哪**：Matlab 的陣列從 1 開始編號，Python、C 等大部分語言從 0 開始。把 Matlab 原型改寫成其他語言時，所有索引都差一格，滿滿的 off-by-one 錯誤。配圖是模擬飛沫傳播的 3D 動畫。
