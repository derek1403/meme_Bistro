# 疊在一起飛的魔女們

![疊在一起飛的魔女們](../images/m0561-witches-java-cpp-python.png)

**一句話**：Java 和 C++ 程式設計師騎著掃帚飛，Python 程式設計師則是站在 C++ 程式設計師的肩膀上。

## 🍸 笑點解說
- **梗在哪**：Python 很多效能關鍵的函式庫（NumPy、PyTorch 等）底層都是 C/C++ 寫的——Python 是被 C++ 載著飛的。
