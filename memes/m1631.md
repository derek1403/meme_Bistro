# 梯度下降卡在局部最小值

![梯度下降卡在局部最小值](../images/m1631-gradient-descent-local-minimum.png)

**一句話**：我：等梯度下降解決問題——梯度下降卡在局部最小值：山姆在麥田裡說：「就是這裡了。如果我再走一步，我就會離 MSE = 0 更遠。」

## 🍸 笑點解說
- **背景知識**：梯度下降每一步都往損失下降最快的方向走；如果走到一個「局部最小值」，四周都是上坡，演算法就會停下來，永遠到不了真正的最佳解（MSE = 0）。
- **梗在哪**：改自《魔戒》山姆的台詞「再走一步，就是我離家最遠的一次」。
