# 𝒪 的四季

![𝒪 的四季](../images/m0422-big-o-seasons.png)

**一句話**：春天是 f(x) = 𝒪(g(x))、夏天是 𝒪(n, 𝔽)、秋天是 𝒪_K、冬天是 𝒪_X——越往後風景越陰沉。

## 🍸 笑點解說
- **背景知識**：同一個字母 𝒪 在數學裡代表完全不同的東西：
  - 𝒪(g(x))：大 O 符號，演算法複雜度，大家都學過。
  - 𝒪(n, 𝔽)：正交群，線性代數／李群。
  - 𝒪_K：數體 K 的整數環，代數數論。
  - 𝒪_X：概形 X 的結構層，代數幾何。
- **梗在哪**：從明亮花海一路走到雪山陰霾——越抽象越冷。
