# 2 ∪ 3 = 3

![2 ∪ 3 = 3](../images/m0181-2-union-3-equals-3.png)

**一句話**：老天，我愛集合論：2 ∪ 3 = 3。

## 🍸 笑點解說
- **背景知識**：在馮紐曼構造中，自然數是集合：2 = {0, 1}、3 = {0, 1, 2}。
- **梗在哪**：因為 2 ⊂ 3，所以 2 ∪ 3 = {0,1,2} = 3。更一般地，m ∪ n = max(m, n)。看起來荒謬的式子，在集合論裡完全正確。
