# 1³ + 2³ + … + 9³ = 2025

![1³ + 2³ + … + 9³ = 2025](../images/m1284-sum-of-cubes-2025.png)

**一句話**：老師在黑板寫下 1³+2³+3³+…+8³+9³ =，全班發呆，只有一個學生舉牌「Coming new year!」——老師寫下：= 2025。

## 🍸 笑點解說
- **背景知識**：前 n 個正整數的立方和 = (1+2+…+n)²。n = 9 時是 45² = 2025。
- **梗在哪**：2025 年是難得的完全平方年，數學圈當年到處都在玩這個恆等式。
