# 把 Claude Pro 交給 vibe coder

![把 Claude Pro 交給 vibe coder](../images/m0054-vibe-coder-claude-pro.png)

**一句話**：把強大的 AI 寫程式工具交給完全不懂程式的人，就像把步槍交給猴子。

## 🍸 笑點解說
- **背景知識**：vibe coding 指不太看程式碼、純靠跟 AI 對話「憑感覺」把程式做出來的寫法。
- **梗在哪**：經典「把 AK-47 交給黑猩猩」梗圖：工具很強，拿的人不知道自己在做什麼，後果難以預料。
