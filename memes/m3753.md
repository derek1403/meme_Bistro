# 一個鋼琴家要多想不開才會在獨奏會排這些曲目？

![一個鋼琴家要多想不開才會在獨奏會排這些曲目？](../images/m3753-piano-recital-touhou.png)

**一句話**：「試論：一個鋼琴家要多想不開才會在獨奏會排這些曲目？」——正式的獨奏會節目單下半場，整段都是東方 Project 的曲子，最後壓軸是〈U.N. オーエンは彼女なのか〉。

## 🍸 笑點解說
- **梗在哪**：〈U.N. オーエンは彼女なのか〉是芙蘭朵露的主題曲，鋼琴改編版以超高難度、音符密集聞名，在正式獨奏會彈這個等於自找苦吃；同時也暴露鋼琴家是東方迷。
