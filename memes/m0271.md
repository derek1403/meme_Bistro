# 一張圖證明你受的是亞洲教育

![一張圖證明你受的是亞洲教育](../images/m0271-triangle-8-15-asian-education.png)

**一句話**：直角三角形兩股 8 和 15——看到的瞬間腦中自動浮現斜邊 17。

## 🍸 笑點解說
- **梗在哪**：8² + 15² = 64 + 225 = 289 = 17²。(8, 15, 17) 和 (3, 4, 5)、(5, 12, 13) 一樣是被亞洲考試訓練到反射性背起來的畢氏三元數。
