# When you need a counterexample in linear algebra——Ol' Reliable

![When you need a counterexample in linear algebra——Ol' Reliable](../images/m2282-ol-reliable-nilpotent-matrix.png)

**一句話**：需要線性代數反例的時候——海綿寶寶打開「老可靠」工具箱，裡面發著光的是矩陣 [[0,1],[0,0]]。

## 🍸 笑點解說
- **梗在哪**：這個 2×2 矩陣幾乎能推翻所有「看似合理」的猜想：它不是零矩陣但平方是零（冪零）、不可對角化、不可逆、特徵值全是 0 卻不是零矩陣、AB ≠ BA 的例子也常用它。
