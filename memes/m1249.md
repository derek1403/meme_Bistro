# 麻醉要加重還是減輕？病人在證明黎曼猜想是錯的

![麻醉要加重還是減輕？病人在證明黎曼猜想是錯的](../images/m1249-surgeon-riemann-sedation.png)

**一句話**：手術台上的病人突然說出「∃ s ∈ ℂ, ζ(s) = 0 | Re(s) > 0 ∧ Re(s) ≠ ½ … ¬RH QED」——麻醉師：「他們這樣的時候，我要加重還是減輕麻醉？」

## 🍸 笑點解說
- **背景知識**：黎曼猜想（RH）說 ζ 函數的非平凡零點實部都是 ½。病人「證明」的內容其實只是把「存在一個反例」寫出來再重複一遍，然後宣布 ¬RH 得證——典型麻醉時的胡言亂語，卻偏偏是千禧年難題。
