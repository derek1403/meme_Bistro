# 我為你寫了首詩：一串二進位，好美

![我為你寫了首詩：一串二進位，好美](../images/m3197-robot-binary-poem.png)

**一句話**：一個機器人送另一個機器人一首詩：「我為你寫了首詩。」「謝謝。」——紙上滿滿的 0 和 1——「好美。」
