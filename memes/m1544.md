# 計算器上的 3 和 5 壞了，要算 50×36 怎麼辦？

![計算器上的 3 和 5 壞了，要算 50×36 怎麼辦？](../images/m1544-broken-3-and-5-calculator.png)

**一句話**：「小明要算帳，但是計算器上的 3 和 5 壞了，要計算 50×36 怎麼辦？」碼農回答：「注意到 50×36 = ∫₀¹ x¹²(1091249949464 − 240010278647x²) ln²(1/x²) / [84204146760(1+x²)] dx = 1800，完成計算。」

## 🍸 笑點解說
- **梗在哪**：明明寫 1800 或 25×72 就好（連 3、5 都不用按），他卻構造了一個完全沒出現 3 和 5 的巨大積分式；「注意到」是數學證明裡憑空冒出神奇技巧的經典嘲諷用語。
