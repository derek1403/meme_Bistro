# 老婆，可以幫我把音量轉小聲一點嗎？——好窩

![老婆，可以幫我把音量轉小聲一點嗎？——好窩](../images/m1626-wife-turn-volume-down.png)

**一句話**：「老婆，可以幫我把音量轉小聲一點嗎？」老婆：「好窩。」——伸手轉了中控台上那顆長得像音量鈕的旋鈕式排檔（P R N D）——最後一張：車子四腳朝天翻在路上。
