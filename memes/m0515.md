# 我夠聰明，修物理沒問題

![我夠聰明，修物理沒問題](../images/m0515-physics-class-harmonic-oscillator.png)

**一句話**：「我修物理課沒問題，看我的。」老師寫出量子諧振子波函數 ψₙ(x) = (mω/πħ)^¼ (1/√(2ⁿn!)) Hₙ(√(mω/ħ)x) e^(−mωx²/2ħ)——眨眼白人。

## 🍸 笑點解說
- **背景知識**：這是量子力學中諧振子第 n 個能階的波函數，包含埃爾米特多項式 Hₙ 與高斯函數，是大二量子力學的標準結果。
