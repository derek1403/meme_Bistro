# 有希的交替：周防有希有 C——長門有希：我也……

![有希的交替：周防有希有 C——長門有希：我也……](../images/m2183-yuki-c-cup-alya.jpg)

**一句話**：《不時輕聲地以俄語遮羞的鄰座艾莉同學》的周防有希捧胸說「我的 C 罩杯沒辦法滿足你嗎？」網友狂喊「有希有 C！！」——《涼宮春日》的長門有希在旁小聲說「……我也……」，阿虛：「不不你沒有 C 吧……」

## 🍸 笑點解說
- **梗在哪**：兩個同名「有希」的角色世代交替——長門有希是 2006 年的人氣角色，胸部平坦；新一代的周防有希搶走了名字和熱度，年輕一輩也不認識長門了（小字：「年輕一輩也不認識我們」）。
