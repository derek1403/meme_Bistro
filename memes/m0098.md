# 心裡想一個數字（理科人版）

![心裡想一個數字（理科人版）](../images/m0098-think-of-a-number-ordinal.png)

**一句話**：心算魔術遇到理科人：答案是「7n」；遇到集合論愛好者：選 ω，最後變成 0。

## 🍸 笑點解說
- **上半**：心算把戲的答案應該跟你想的數無關，但這題照算是 ((n+4)·3−7)·2 + n − 10 = 7n，出題者自己算錯，被理科人當場抓包。
- **下半（難）**：序數加法不交換：2 + ω = ω（前面加有限個還是 ω），但 ω + 2 ≠ ω。所以 (2+ω)·2 = ω·2，再減掉 ω·2 就是 0，不是預期的 4。魔術師的「代數不變性」在超限序數裡失靈。
