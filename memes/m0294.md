# i + 1/i = 0

![i + 1/i = 0](../images/m0294-i-plus-one-over-i-zero.png)

**一句話**：兩個 Soyjak 對著 i + 1/i = 0 驚呼。

## 🍸 笑點解說
- **梗在哪**：1/i = −i，所以 i + 1/i = i − i = 0。看起來很神奇，其實只是一步有理化。
