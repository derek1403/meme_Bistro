# 藏頭藏尾我都看了——妳當我是朋友的話就斜著看

![藏頭藏尾我都看了——妳當我是朋友的話就斜著看](../images/m1846-acrostic-read-diagonally.jpg)

**一句話**：男生傳了一首七行七言詩給小花；小花：「藏頭藏尾我都看了，很感動，但是我只想做朋友。」男生：「妳當我是朋友的話，就斜著看。」

## 🍸 笑點解說
- **梗在哪**：藏頭是「我會一直喜翻（歡）你」，被發了好人卡；但從左上往右下斜著讀（第 n 行第 n 字）是「我向你周轉三千」——既然是朋友，那就借錢吧。
