# 說 world wide web 比說 www 還快

![說 world wide web 比說 www 還快](../images/m0350-world-wide-web-faster.jpg)

**一句話**：「怎麼了寶貝？」「我發現說 world wide web 比說 www 還快。」——兩個人一起陷入沉思。

## 🍸 笑點解說
- **梗在哪**：W 念 double-u 有三個音節，www 共九個音節；world wide web 只有三個。縮寫反而比原文長。
