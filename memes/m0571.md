# 怎麼解 3x² − x = 8？先考慮伽羅瓦群

![怎麼解 3x² − x = 8？先考慮伽羅瓦群](../images/m0571-solve-quadratic-galois-theory.png)

**一句話**：「怎麼解 3x² − x = 8？」猛男們輪番回答：先考慮添加根得到的體擴張、它的自同構群、再檢查伽羅瓦群的導出列是否終止於平凡群——答案就在那裡！

## 🍸 笑點解說
- **背景知識**：伽羅瓦理論說，一個多項式能用根式解，若且唯若它的伽羅瓦群是「可解群」（導出列最後會變成平凡群）。
- **梗在哪**：這是國中的二次方程，用公式解一行就好；大家卻拿出證明「五次方程無根式解」的核武器。
