# 諾貝爾獎得主 Parisi：會議報名人數 N(t) = c·ln[T*/(T*−t)]

![諾貝爾獎得主 Parisi：會議報名人數 N(t) = c·ln(T*/(T*−t))](../images/m2382-parisi-deadline-registration-log.png)

**一句話**：「諾貝爾獎得主 Giorgio Parisi 在其中一篇論文中展示：當接近截止日期時，會議報名人數可以用 N(t) = c·ln[T*/(T*−t)] 擬合。」——實際報名資料的圖在截止日前垂直暴衝。

## 🍸 笑點解說
- **梗在哪**：這條曲線在 t → T*（截止日）時發散到無限大——用數學證明大家都在最後一刻才報名。原 PO 還順手推導了交報告人數的式子。
