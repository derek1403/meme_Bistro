# 用延長線解釋程式控制結構

![用延長線解釋程式控制結構](../images/m3306-control-flow-power-strips.png)

**一句話**：一串轉接頭是 if else if else；多孔開關插座是 switch；自己插自己的延長線是 while(True)；一條接一條的延長線是 foreach；一團亂纏的電線是 try；旁邊的無熔絲開關是 catch。
