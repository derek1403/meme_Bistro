# 等一下寶貝，有人在臉書說 HTML 不是程式語言

![等一下寶貝，有人在臉書說 HTML 不是程式語言](../images/m1852-html-not-programming-language.png)

**一句話**：女生：「寶貝你可以碰我了嗎？」男生（手還在敲鍵盤）：「等一下寶貝，臉書上有個人說 HTML 不是程式語言，我需要——同意他。」

## 🍸 笑點解說
- **梗在哪**：原本的梗是「我需要去反駁他」（someone is wrong on the internet），這裡劃掉改成「同意」——HTML 是標記語言，真的不算程式語言。
