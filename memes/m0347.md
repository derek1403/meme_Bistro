# 物理系教授語錄

![物理系教授語錄](../images/m0347-physics-professor-quotes.png)

**一句話**：「學數學的看到這一步會生氣，但我們不去管它」「這個函數一定得是性質良好的，如果不是，那就先假設它是」「光速 = 重力常數 = 普朗克常數 = 波茲曼常數 = 1」「1/137」。

## 🍸 笑點解說
- **背景知識**：物理推導常直接交換極限、積分與求和，或假設邊界項為 0，數學上需要額外證明。「令常數 = 1」是自然單位制；1/137 是精細結構常數，物理學家最愛的神秘數字。
- **梗在哪**：每一句都是物理系學生在課堂上聽過無數次的台詞。
