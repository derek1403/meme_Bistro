# 求 lim sin(x)/x 的四種境界

![求 lim sin(x)/x 的四種境界](../images/m0236-sinx-over-x-galaxy-brain.png)

**一句話**：夾擠定理 → 羅必達 → 觀察圖形 → 「近似一下 sin x = x」，大腦越來越亮。

## 🍸 笑點解說
- **背景知識**：這個極限是推導 (sin x)′ = cos x 的基礎。
- **梗在哪**：用羅必達或 sin x ≈ x 其實是**循環論證**——兩者都已經用到了 sin x 的導數（也就是這個極限本身）。越「聰明」的解法越不合法，只有最樸素的夾擠定理是正解。
