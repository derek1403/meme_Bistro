# 學生畢業後：我只知道 (a+b)² = a² + b²

![學生畢業後：我只知道 (a+b)² = a² + b²](../images/m1507-only-know-a-plus-b-squared.png)

**一句話**：學生畢業後——「我不知道要怎麼找工作」「我不知道要怎麼繳稅」「我只知道 (a+b)² = a² + b²」

## 🍸 笑點解說
- **梗在哪**：學校說會教實用知識，但學生最後只記得一條數學公式——而且還是錯的：正確是 (a+b)² = a² + 2ab + b²，寫成 a² + b² 是有名的「新生之夢（freshman's dream）」錯誤。
