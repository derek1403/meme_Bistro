# lim x→0 在追 x = 0

![lim x→0 在追 x = 0](../images/m1999-limit-x-to-0-chasing.png)

**一句話**：身穿「lim x→0」的大姊姊慢慢靠近穿著「x=0」的小男孩——小男孩察覺不對拔腿就跑，大姊姊全速追上。

## 🍸 笑點解說
- **梗在哪**：極限 x→0 表示「無限接近 0 但不等於 0」——所以它永遠追不到真正的 x = 0。
