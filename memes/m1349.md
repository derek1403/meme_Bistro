# 在路上遇到直角三角形：8、15、17

![在路上遇到直角三角形：8、15、17](../images/m1349-right-triangle-8-15-17.png)

**一句話**：「在路上遇到直角三角形」——地磚上的陽光剛好切出一個三角形，數磚塊：兩股 8 和 15，斜邊 17。

## 🍸 笑點解說
- **背景知識**：8² + 15² = 64 + 225 = 289 = 17²，(8, 15, 17) 是一組畢氏三元數——而且剛好可以用地磚數出來。
