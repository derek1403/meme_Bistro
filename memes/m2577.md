# 牛頓：要用力一點追啊——會有反作用力啦，懂？

![牛頓：要用力一點追啊——會有反作用力啦，懂？](../images/m2577-newton-chase-harder-reaction.jpg)

**一句話**：長輩說「追女生要用力一點」，牛頓回：「會有反作用力啦，懂？$F_{AB} = -F_{BA}$，還有 $F = ma$，追越用力她跑越遠。」
