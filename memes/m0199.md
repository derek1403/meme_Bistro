# 人形洞要接吻才能過？妹紅和輝夜選擇直接撞牆

![人形洞要接吻才能過？妹紅和輝夜選擇直接撞牆](../images/m0199-mokou-kaguya-through-wall.png)

**一句話**：牆上挖了一個「兩人接吻」形狀的人形洞，妹紅和輝夜要擺出這個姿勢才能通過；兩人互看一眼，面無表情——最後各自直接撞穿牆壁走過去，留下兩個獨立的人形洞。

## 🍸 笑點解說
- **背景知識**：東方 Project 的藤原妹紅與蓬萊山輝夜都是不老不死之身，兩人是宿敵，常常互相廝殺。
- **梗在哪**：綜藝節目「人形洞牆」要參賽者擺出指定動作才能穿過。這次的動作偏偏是接吻，感情超差的兩人寧可硬撞牆，也不肯親對方。
