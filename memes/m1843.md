# 等等，我是叫的優香和愛麗絲到我辦公室來，你們是誰？

![等等，我是叫的優香和愛麗絲到我辦公室來，你們是誰？](../images/m1843-yuuka-alice-office-who.png)

**一句話**：「等等，我是叫的優香和愛麗絲到我辦公室來，你們是誰？」——走進辦公室的是東方 Project 的風見幽香和愛麗絲·瑪格特洛依德。

## 🍸 笑點解說
- **背景知識**：《蔚藍檔案》裡的老師有學生叫早瀨優香、天童愛麗絲；東方 Project 剛好也有同名（音）角色——叫錯作品的人來了。
