# 被詛咒的行與列

![被詛咒的行與列](../images/m0012-cursed-rows-columns.png)

**一句話**：同一張試算表，台灣和中國對「行」「列」的定義剛好相反，看久會精神錯亂。

## 🍸 笑點解說
- **背景知識**：台灣習慣「row = 列（橫的）、column = 行（直的）」；中國大陸剛好相反：「row = 行、column = 列」。
- **梗在哪**：左右兩張圖各自都「正確」，但放在一起就是互相矛盾的詛咒。讀矩陣、看 Excel 教學、寫論文時兩岸資料混著看的人都被害過。
