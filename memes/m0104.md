# 什麼東西八條腿，愛吃菜還餵同伴吃菜

![什麼東西八條腿，愛吃菜還餵同伴吃菜](../images/m0104-eight-legs-dietitians.png)

**一句話**：答案是「四個營養師」——營養師本人：是不是對我們有什麼偏見？

## 🍸 笑點解說
- **梗在哪**：謎題聽起來像在描述昆蟲或動物，結果是整天叫人多吃蔬菜的營養師。回答的帳號叫「菜鳥」、出題的叫「地瓜鳥」，連 ID 都在玩菜。
