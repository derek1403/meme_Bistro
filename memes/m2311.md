# 不定積分時 C 跟著你——定積分時 C 搭船走了

![不定積分時 C 跟著你——定積分時 C 搭船走了](../images/m2311-constant-c-abandons-definite.png)

**一句話**：湯姆貓（C）開心地牽著傑利鼠（∫f(x)dx）的手；換成定積分 ∫ₐᵇ f(x)dx 時，C 搭著船遠去，傑利在碼頭揮手帕送別。

## 🍸 笑點解說
- **梗在哪**：不定積分的答案一定要加上積分常數 +C；定積分算的是 F(b) − F(a)，兩個 C 互相抵銷掉，所以 C 就不見了。
