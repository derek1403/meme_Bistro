# T = 2π√(mk)/k

![T = 2π√(mk)/k](../images/m0145-rationalized-period-formula.png)

**一句話**：物理老師說 √2/2 比 1/√2 優美——那彈簧週期就寫成 T = 2π√(mk)/k 吧。

## 🍸 笑點解說
- **背景知識**：彈簧振子週期 T = 2π√(m/k)。國高中數學要求「分母有理化」，所以 1/√2 要寫成 √2/2。
- **梗在哪**：把分母有理化硬套到物理公式，得到一個數學上等價、但看起來非常彆扭的寫法：√(m/k) = √m/√k = √(mk)/k。
