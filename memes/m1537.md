# 女人的心思就像是 X+2=0

![女人的心思就像是 X+2=0](../images/m1537-rick-x-plus-2-rich-kid.png)

**一句話**：瑞克：「女人的心思就像是 X+2=0。」莫蒂：「求解？」瑞克：「富二代進去就解開了！」

## 🍸 笑點解說
- **梗在哪**：X + 2 = 0 的解是 X = −2，也就是「負二」，諧音「富二（代）」——把 −2 代進去方程式就解開了。
